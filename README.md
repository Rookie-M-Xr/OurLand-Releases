# OurLand

OurLand 是一款 Windows 桌面信息岛：收起时是贴在屏幕边缘的小胶囊（默认在上沿），展开后可以看正在播放的音乐和歌词、天气和常用快捷方式，新消息通知会从胶囊旁边挤出对应应用的图标。

当前版本 **1.1.7**。下载请到 [Releases](https://github.com/Rookie-M-Xr/OurLand-Releases/releases) 页面。

---

## 主要功能

- **胶囊**：无边框置顶，默认贴在屏幕上沿，也可以拖到其它边吸附。闲置时显示时钟、天气和表情。
- **音乐与歌词**：识别系统里正在播放的媒体，展开后显示歌词（含译文）、进度和播放源，可在多个播放源之间切换。
- **通知**：微信、QQ、TIM、飞书、钉钉有新消息时，从胶囊旁边弹出应用图标和红点，点一下回到对应应用的主窗口。
- **专注模式**：右键胶囊开始倒计时，专注时长可在设置里调整。
- **快捷方式**：最多固定 6 个常用应用，展开后一键启动。
- **外观**：纯色、撞色、渐变、透明或毛玻璃，长度、宽度、字号和不透明度都可以调。
- **多屏**：可以出现在你正在使用的屏幕，在扩展屏交界处贴边。
- **更新提醒**：有新版本时在岛上提示。1.1.6 及更早版本的在线升级无法完成，请手动安装一次 1.1.7 或更新的版本。

## 适配说明（以 1.1.7 为准）

下面按实际能力列出目前适配的媒体源和通知软件。只要播放器把正在播放的内容交给 Windows 系统媒体控件，一般都能在岛上显示和控制；未单独列出的播放器，歌词可能对不上。

### 媒体源

| 播放器 | 支持内容 | 已知限制 | 状态 |
| --- | --- | --- | --- |
| QQ音乐 | 歌名 / 歌手、封面、歌词（含译文）、进度、播放 / 暂停 / 上一首 / 下一首 | 歌词和封面按歌名、歌手在线匹配，偶尔对不上 | 已验证 |
| 网易云音乐 | 歌名 / 歌手、封面、歌词（含译文）、进度、播放 / 暂停 / 上一首 / 下一首 | 未在网易云里开启系统媒体控件时，播放 / 暂停走的是切换键（按当前是播还是停来决定）；上一首 / 下一首依赖网易云自己的快捷键，被其它软件占用时按钮会不可用。可在网易云「设置 → 系统」里开启系统媒体控件 | 已验证 |
| Edge 网页音视频 | 标题、播放控制、播放源切换；系统提供时也会显示封面和进度 | 普通标签页通常只会显示成一个来源（浏览器限制），已安装的网站应用才可能单独出现；按标题检索歌词，不保证有 | 已验证（标题、控制、来源切换） |
| 其它使用系统媒体控件的播放器 | 歌名 / 歌手、播放控制；系统提供时显示封面和进度；会按歌名、歌手检索歌词 | 未对接系统媒体控件的播放器不会出现；歌词可能匹配不到 | 理论可用 |

### 通知软件

不显示未读条数，只用图标上的红点表示「有未读」。

| 应用 | 支持内容 | 状态 |
| --- | --- | --- |
| 微信 | 横幅文字、官方图标红点、点击唤起主窗口 | 已验证 |
| QQ | 横幅文字、官方图标红点、点击唤起主窗口 | 已验证 |
| 钉钉 | 横幅文字、官方图标红点、点击唤起主窗口 | 已验证 |
| 飞书 | 横幅文字、官方图标红点、点击唤起主窗口 | 支持但未验证 |
| TIM | 横幅文字、官方图标红点、点击唤起主窗口（与 QQ 同一套逻辑） | 支持但未验证（仅做过简单测试） |

说明：

- 横幅有通知正文时显示正文，没有正文时显示「某应用收到一条消息」。微信、飞书、钉钉主要靠任务栏闪烁获知新消息，通常没有正文，横幅多为这句提示。
- 该应用的主窗口被切到本机前台后，红点和横幅会清掉；在手机上已读，电脑这边不会清。
- 点击图标或横幅只打开该应用的主窗口，不会跳到某一条具体聊天。
- 目前只支持表中列出的应用，其他应用的通知暂不显示。
- QQ / TIM 如需显示通知正文，请到「管理 → 通知」完成一次注册。

## 下载与安装

1. 打开 [Releases](https://github.com/Rookie-M-Xr/OurLand-Releases/releases)，进入最新版本。
2. 下载 `OurLand-Setup-1.1.7.exe`，双击运行，按向导完成安装。
3. 需要 QQ 通知或系统定位时：右键胶囊 →「管理」→「通知」，点击注册（会弹出一次系统权限确认）。完成后彻底退出 OurLand 再重新打开。

> **从旧版升级**：1.1.4 及更早版本没有更新器；1.1.6 及更早版本的在线更新也无法完成。请直接下载最新安装包，手动安装即可。

### 校验安装包（可选）

每个版本都附带 `.sha256` 文件，里面是安装包的 SHA256。下载安装包和对应的 `.sha256` 后，在 PowerShell 里运行：

```powershell
Get-FileHash .\OurLand-Setup-1.1.7.exe -Algorithm SHA256
```

输出的 `Hash` 与 `.sha256` 文件里的值一致（不区分大小写）即为完整。

## 检查更新怎么用

> 1.1.6 及更早版本可以检查并提示新版本，但在线升级无法完成，请到 Releases 页面手动下载安装包。

- **自动检查**：启动后不久会自动检查一次，之后每天一次，可在 管理→设置 里关闭。发现新版本时，展开卡片上会出现更新按钮，可以看到下载进度，也可以取消。
- **手动检查**：右键胶囊 →「管理」→「设置」→「更新」，点「立即检查」。
- **跳过此版本**：不想升级到某个版本时可以跳过，自动检查不会再提示它；手动检查仍会告诉你。
- **原地升级**：下载并校验通过后会静默升级，只会弹出一次系统权限确认；旧版自动退出，装完自动重新打开。
- 是否接收预览版，也可以在 管理→设置 里选择。
